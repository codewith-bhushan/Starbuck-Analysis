
# Starbucks Sales Analysis


The **Starbucks Sales Analysis** project is an end-to-end data analytics project focused on analyzing sales performance, product trends, and business insights. The project uses **PostgreSQL** for data querying and transformation and **Power BI** for creating an interactive dashboard.

The objective is to transform raw sales data into meaningful insights that can support better business decisions and improve overall performance.

---

## 🎯 Problem Statement

Starbucks generates a large amount of transactional data across different stores, products, and time periods. Analyzing this data manually can make it difficult to identify important sales patterns and customer preferences.

This project aims to answer key business questions such as:

* Which products generate the highest sales?
* Which product categories perform best?
* What are the sales trends over time?
* Which locations or stores generate higher revenue?
* What are the peak sales periods?
* How can business performance be improved using data insights?

## 🚀 How to Run the Project

### Step 1: Download the Dataset

Download the dataset and save it in the project directory.

### Step 2: Set Up PostgreSQL

* Create a database.
* Import the dataset.
* Create the required tables.
* Run the SQL queries from the project.

### Step 3: Perform SQL Analysis

Execute the SQL queries to analyze beverage categories, nutritional values, caffeine levels, and other business metrics.
